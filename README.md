# Template Profile

[日本語](README.ja.md)

A small browser game where you build a self-introduction for a dating-app-style profile. You pick words for each blank in a fixed template, and the result is a profile that is a little off.

Play it: https://paochanz.github.io/template-profile/

## Structure

- `index.html`: the published page. It is generated by `build.py`, so do not edit it directly.
- `src/data.json`: the vocabulary, one option per line.
- `src/core.js`, `src/ui.js`, `src/parts.js`, `src/style.css`: the game itself.
- `build.py`: run `python3 build.py` to generate `index.html`.

## Privacy

- Your nickname, photo, and age settings are stored only in your browser (localStorage). They are never sent anywhere.
- The page loads the Zen Maru Gothic font from Google Fonts.
